# Future Skills Academy — zero-cost EdTech website

## Included
- Responsive landing page
- Programs
- Recurring membership pricing
- Free demo registration
- FAQ
- Mobile navigation
- Local lead capture using browser localStorage
- SEO metadata

## Run locally
Open `index.html` in a browser.

## Deploy free
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Enable Pages from repository settings.
4. Use the generated `github.io` URL.

### Cloudflare Pages
1. Create a free Cloudflare account.
2. Create a Pages project and upload the folder.
3. Deploy.
